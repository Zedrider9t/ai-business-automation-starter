# Contributing

Thanks for your interest in improving AI Business Automation Starter.

## Development workflow

1. Open an issue for substantial changes.
2. Create a focused branch from `main`.
3. Keep changes small and reviewable.
4. Run `npm run typecheck` before opening a pull request.
5. Explain the business use case as well as the technical change.

## Pull requests

A good pull request should include:

- What problem it solves
- Why the change is useful
- Any trade-offs or limitations
- How it was validated

## Safety and privacy

Do not include real customer data, credentials, access tokens, private URLs, internal company documents, or confidential project information in examples, issues, tests, or pull requests.
